# 覆盖说明

公开仓库仅包含通用指标定义和演示样例，不发布任何账户的实际统计状态、订阅、用量或费用。基础目录见 [产品与计量表](../coverage/cloudflare-products.md)，额外计量由连接账户的订阅发现，不能把目录项数当作完整计价承诺。

| 状态 | 含义 |
|---|---|
| ok | 来源取得有效用量，可能为明确零 |
| no_records | 正确来源成功返回但无记录；显示 —，保留卡片 |
| partial | 入账延迟、窗口不足、单位或计量规则未核实；不展示完整余额 |
| not_enabled | 来源明确确认未开通 |
| error | 本次读取失败；保留同账户、同周期的最后成功结果与时间 |

金额按固定费、已报告费用、未入账部分估算、尚未计价分开。容量不能替代 GB-month，管理事件不能冒充计费操作，每日/自然月/订阅周期不能混算。合计不代表包含税费、折扣、合同价格和所有未计价项的最终发票。

演示模式由 src/demo.ts 生成，与真实账户配置隔离。公开截图仅保留明确标注的演示页面。真实来源的验证结果保存在本地私有目录，不能以此文件替代某个账户的完整对账。
