# 凭据与本地配置

## 两种只读 Token

项目连接一个 Cloudflare 账户，支持两种凭据。它们均用于读取数据，不用于部署或修改云资源。

| 凭据         | 主要用途                                |
| ------------ | --------------------------------------- |
| 账户级 Token | 账户内产品资源、用量统计与 GraphQL 来源 |
| 用户级 Token | 部分账单、订阅、Builds 与用户上下文来源 |

在 Cloudflare 控制台创建对应类型的 API Token，将资源范围限制为同一个目标账户，只赋予所需产品的读取权限。产品与统计接口可能需要不同的权限；请按实际使用的产品授予读取权限，不要用 Global API Key 或写入权限替代。

Cloudflare 的权限名称与 API 可用范围可能变化，参考 [创建 API Token](https://developers.cloudflare.com/fundamentals/api/get-started/create-token/) 和 [账户拥有的 Token](https://developers.cloudflare.com/fundamentals/api/get-started/account-owned-tokens/)。项目不承诺一个固定权限组合能够读取所有产品。

## 在页面中保存

1. 启动本地服务，打开 `/settings`。
2. 输入账户级 Token，点击验证，通过后保存。
3. 输入用户级 Token，同样验证并保存。两个 Token 必须只访问同一个账户；多账户范围会被拒绝。
4. 返回总览，点击「立即刷新」。新开或重载页面也会触发一次刷新，内部切页复用当前结果。
5. 调整权限后，可在设置页重新核查来源能力，再手动刷新。

两个 Token 独立保存、替换、清除。全部清除后，可连接另一个账户；旧账户快照不会显示为新账户数据。

「验证成功」仅说明凭据能通过验证并定位目标账户，不表示每个产品和账单来源都有权限或完整数据。适配器在认证或权限失败时会尝试另一种已配置凭据；仍无法取得可靠数据的指标从产品页及导航隐藏。曾成功读取的指标遇到临时错误时保留同周期的上次结果和时间，恢复后自动显示新数据。

## 密钥与存储

`npm run setup:local` 在首次运行时生成 32 字节随机十六进制主密钥，写入被 Git 忽略的 `.dev.vars`，并应用本地迁移。重复运行不会覆盖已有密钥。

| 位置                | 内容                                   | 是否提交     |
| ------------------- | -------------------------------------- | ------------ |
| `.dev.vars.example` | 空配置模板                             | 是           |
| `.dev.vars`         | 本地 `TOKEN_ENCRYPTION_KEY`            | 否           |
| `.wrangler/`        | 本地 D1、运行缓存和日志                | 否           |
| `.private/`         | 私有验收材料、原始截图和测量结果       | 否           |
| D1 配置行           | AES-GCM 加密的 Token、末四位与验证时间 | 不导出到仓库 |

完整 Token 会经过服务端验证和加密，不写入浏览器存储，也不通过读取接口返回。AES-GCM 保护数据库中的凭据；它不代替网站访问控制。主密钥与数据库需要配套保管，更换主密钥后要重新保存 Token。

## 常见问题

| 现象                                 | 检查方式                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------- |
| 提示先配置加密密钥                   | 运行 `npm run setup:local`，重启开发服务器；生产环境需单独设置 Secret。         |
| Token 能验证，但某些产品未显示       | 核对相关产品的读取及统计权限、资源范围、套餐资格和 API 可用性，再重新核查来源并刷新。 |
| 提示两个 Token 账户不一致            | 将两个 Token 限制到同一账户；确需切换时先清除原账户的两个凭据。                 |
| 部分指标显示「暂无记录」或「待核实」 | 查看该项来源和覆盖说明，不要按零用量或零费用理解。                              |
| 刷新失败后仍显示旧数值               | 这是最后成功值；保留原数据时间，修复网络或权限后手动刷新。                      |
| 演示页面不能保存 Token               | 删除地址中的 `demo` 参数后重新打开设置页。演示与真实模式分别运行。              |

远程配置前先完成 [部署与访问保护](deployment.md)。
