# 视觉与图表规范

视觉参考：`concept.png`。总览、Workers 详情、双 Token 设置、手机视图共用一个系统。概念中的演示数字不作为产品计价依据；例如 CPU 必须以真实 ms 和 3000 万包含额度实现。

背景 `#f7f8fa`，白色表面，深蓝灰正文，Cloudflare 橙 `#f38020` 为刷新与主额度强调；绿色、蓝色用于不同指标，红色只表示超额。桌面侧栏 228px，正文边距 36px；手机 18px，抽屉导航，360px/390px 均测试。

使用 shadcn 官方 new-york-v4 的 Button、Input、Label、Sheet 等源码，Radix 行为与键盘焦点管理。CLI 两次遭遇 Socket closed 后，直接读取相同官方 registry JSON 获取源码，并将 `cn` import 映射到项目 utils。没有替换为视觉仿制控件。

图表任务为当前额度监控：React 负责状态与标签，SVG 负责圆环，CSS 负责进度条。比例使用精确用量/包含额度；圆环图形最多填满，但数字保留 125% 等真实比例和超出量。未知/范围不足无假满余额；容量、硬性上限、订阅额度分别标注。图表最多显示当前产品的指标；总览只呈现三个核心额度，其他产品列表可导航。

不使用趋势、随机波动、canvas/WebGL 或动画采样。环形过渡只在数值变化时触发，离屏关闭过渡，隐藏页面暂停持续的加载动画；系统 reduced-motion 关闭动效并保留全部数字。所有关键数值无需 hover。
