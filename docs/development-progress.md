# 开发状态

本地功能已实现，支持部署到 Cloudflare Workers。公开仓库不保存特定账户的部署配置、运行状态、订阅、用量或费用。

- React/shadcn 响应式页面、独立产品路由、动态额度与费用覆盖提示。
- 双 Token 独立验证、AES-GCM 加密保存、替换和清除，同账户约束。
- 稳定指标登记、同账户同周期的最后成功值、配置版本隔离。
- 十进制费用、订阅/自然月/每日/瞬时周期分开，已报告金额与未入账增量分列。
- 只读来源适配、有界并发和刷新租约；仅打开/重载与手动刷新，不轮询、不存历史序列。
- 单元/Worker 集成测试、生产构建和 dry-run；验证方法见 [本地验证](acceptance/local-page-review.md)。
- 来源或价格不足时继续显示 partial/未计价，不声称所有产品均可完整对账。

生产配置与线上验证方式见 [部署说明](deployment.md)。实例专属的部署记录与原始账户验收证据留在本地 .private，不属于公开仓库。
