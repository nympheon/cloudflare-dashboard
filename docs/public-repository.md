# 公开仓库说明

公开内容为程序、迁移、空配置模板、通用产品定义、技术文档和明确标注的演示图。不会发布真实账户的 API 结果、订阅清单、用量/账单、账户/区域标识、Token 尾号、真实设置截图或个人机器路径。

## 仅本地保存

.gitignore 排除 .dev.vars、.env、.wrangler、.private、node_modules、dist、日志、数据库、私钥、IDE 和本机工具配置。空模板 .dev.vars.example 可以提交。主密钥仍供本地 D1 解密使用；不要删除现有主密钥或把真实值填入模板。

原始文档与截图保存在 .private/pre-publication/，仅用于本地留档。npm run measure:local 的新测量写入 .private/acceptance/。这些材料含真实数据，不应使用 git add -f 纳入仓库。

## 提交检查

初始化 Git 后，先用 git status --short 和 git diff --cached --name-only 检查文件清单；不要强制添加被忽略内容。公开文档中的截图须来自独立演示模式，遮住账户名仍可能暴露 Token 尾号、用量、账期和账单，不能代替完整脱敏。

.gitignore 只约束新文件；若以后曾经跟踪敏感文件，需要先移出 Git 索引并检查历史。推送前应再次扫描实际暂存区与拟发布的提交，不要只扫描工作目录。脱敏不需要修改 Cloudflare 账户、Token 权限或本地凭据。

公开图片来自开发模式下的合成演示。总览、超额与失败场景均保留「演示数据」标识，不使用真实模式截图替代；设计概念图只是视觉参考，不作为功能验收证据。

## 数据边界

基础目录是代码定义，不表示某个账户已开通对应产品。账户专属的额外计量、来源权限、保留期、计价完整性由运行时核查。演示数字是合成样例，不能当作真实用量或性能验收证据。
